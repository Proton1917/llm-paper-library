TML 架构说明
块摘要里究竟存了什么？

普通残差把各个子层的输出一路加到同一份表示上。Inkling 的块注意力残差（Block AttnRes）保留块内的加法，却把不同块的和分开存。对同一 token，B2 的完整块和就是第 7–12 层六个注意力输出、六个 MoE 输出的逐坐标和。它仍是一条 2304 维向量，不是一段压缩文字。B3 另有一条同样宽的向量；下一遍可以分别给两条向量赋权，而不用只接收第 18 层的最后一次输出。

仍用深度读取的打分与加权方法，但候选只有第一轮完成的 B2、B3。每个入口用独立的读头 usu_sus​ 选配同一位置的两条向量；每条消息 msm_sms​ 的宽度仍是 2304。这里的 MMM 表示 MoE。

自注意力用其中三条消息。给 Q 的消息可以偏向 B3，而给 K 的消息可以偏向 B2。此时还没有投影出 Q、K、V。

MoE 取第四条消息。即使注意力刚更新了本轮 B3，第四个读头的候选仍是上一轮的两份完整块和。

选中了上一轮某一块，是否等于会采用它？

不一定。读头决定消息来自哪个块；门控再决定每个坐标保留多少当前输入 xxx、加入多少消息 msm_sms​。⊙\odot⊙ 表示逐坐标相乘。两组系数由当前输入与消息共同算出，不要求相加等于 1。

训练刚引入循环时，门被初始化为保留当前输入、挡住整个消息。随后模型才逐步学会采用上一遍的信息，这使训练能从原有的单遍变换出发。TML 门控设计

第 16 层的 Q、K、V 路径共用本轮读出的 xAx_AxA​，但各有消息和门控。三份混合结果分别归一化，再送进各自的投影。

MoE 的门接到新读出的 xMx_MxM​ 和上一轮消息 mMm_MmM​。融合后才归一化、路由到专家；消息不会直接写进 B3。

层内两次写回，哪一份状态会交给下一层？

hA=h+oAh_A=h+o_AhA​=h+oA​hout=hA+oMh_{\mathrm{out}}=h_A+o_Mhout​=hA​+oM​

第 16 层用局部因果自注意力：Q 在当前位置查询，K、V 来自不晚于它的窗口内位置。序列注意力沿 token 位置读取；前两种读取都在同一个位置选择块。算出的 oAo_AoA​ 加到原 B3 部分和 hhh，得到供 MoE 读取的 hAh_AhA​。

MoE 为每个 token 从 128 位专家中选 8 位，合并其结果。它的输出 oMo_MoM​ 加到已经更新的 hAh_AhA​，而非原来的 hhh。第 17 层读到的是两次写入后的 houth_{\mathrm{out}}hout​。

这里的 oAo_AoA​、oMo_MoM​ 均表示实际写入向量，已计入各子层输出侧的短因果卷积。

计算代价

权重复用，计算和缓存分遍计

26.4B

模型存了多少参数

这是整个模型的总参数量。中间 12 层在第二、三遍仍调用同一套权重，不需要复制成三套。每层的前馈部分是稀疏 MoE，每个 token 从 128 个专家中选择 8 个。

5.4B / token

重复使用也计入的有效活跃参数量

按模型卡口径，单遍约 3.4B，额外两遍各用约 1.0B，所以三遍约为 5.4B。这里算的是权重被使用的量；它不是独立参数数目，也不能直接换算成毫秒。

48次 / token

展开后实际走过多少层

前段和末段各走 6 层，中段走 3 × 12 层。在固定三遍版的 vLLM 实现中，同一物理层的不同遍各有自己的键值缓存（KV cache）。各遍输入可以不同，算出的 K、V 也可以不同。

多跑一遍，与多写一个思维链 token 有什么不同？

写出一个 token，会在上下文末尾增加一个离散符号；之后的生成能沿序列读回它。多跑一遍循环则在已有位置上更新内部向量，不会给序列新增位置。模型也可以继续输出思维链，两种计算可以同时发生。

04

实验证据

多跑几遍，什么会变好？

正式版固定跑三遍。要把遍数和模型本身分开，得换用可变循环研究版：保持同一套权重，只改中段执行的遍数。

同样的计算，放在哪一段？

两组训练计算量相同，都跑三遍。在 28 项评测中，有 27 项是循环中段（第 7–18 层）比循环末段（第 13–24 层）带来更大的准确率增益。作者推测，首尾层更多负责表示转换，中间层更适合反复加工。位置消融

同样的权重，哪种任务受益？

边已经写在上下文里时，多算两遍可以帮助模型沿边找节点；闭卷回忆事实的分数却没有持续上升。三遍也不是硬上限：不写思维链、必须连续查几张表的 N-Hop Lookup，到十遍仍有提升。逐跳查表实验

实测的一条跨轮路径

Goodfire 在 400 篇 FineWeb 文档的 13,233 个 token 上观察到，第 18 层在前两遍都向同一激活坐标 d2027 写入正峰。第二遍第 13 层为 Q 读消息时，单这一坐标就贡献了 B3 相对 B2 打分差的 17%。这个比例衡量的是选哪一块，不是答案里 17% 的信息来自第 18 层。Goodfire 图 7、8

512K 成本对照里的 140% 是什么？

这次比较用的是两个未剪枝版本。非循环版的训练计算量少 7.5%，但要达到循环版在 512K token 智能体轨迹上的同一损失，非循环版需要多 140% 的推理计算，即循环版的 2.4 倍。这不是逐 token 的运行时间之比。TML 成本对照
